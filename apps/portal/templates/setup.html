Deployment guide

Run it your way

The engine is platform-neutral. OpenClaw, Claude Code, Codex, and plain shell all call the same typed CLI.

01

Choose an adapter

Generate platform-specific instructions without copying secrets into an agent context.

uv run threat-radar setup generate --platform codex
02

Configure discovery

Provide Brave and xAI keys through environment variables or your platform secret store.

BRAVE_API_KEY · XAI_API_KEY
03

Run locally

SQLite and local immutable objects are the default portable storage profile.

uv run threat-radar portable run --json
04

Open the portal

Loopback is the safe default. LAN mode requires an access token and private network source.

scripts/run-portal.sh --lan
