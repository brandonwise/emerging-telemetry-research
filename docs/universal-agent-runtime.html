One research, replaceable agents

Collection and publication stay deterministic. Agent platforms plug into one narrow, typed review boundary, so OpenClaw can be swapped for Codex, Claude, Perplexity, or another compatible provider without moving evidence or changing the safety model.

As built Multi-surface discovery · five-role DAG · plan/shadow/active modes · immutable reviews · source and agent evals
Source diversity is measured, not assumed Reddit, TikTok, GitHub, web research, official feeds, and X keep distinct surface IDs even when a shared search provider retrieves them.
Agents are useful but untrusted They can challenge, explain, and request follow-up. They cannot browse, call tools, access secrets, rewrite the score, or publish.
Portability lives at two seams Source adapters map into one signal contract. Agent providers map into one assessment contract. Everything between and after those seams is shared code.
