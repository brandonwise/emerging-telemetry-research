OpenClaw Emerging Threat Radar

A multi-agent early-warning system that discovers credible vulnerabilities, exploitation, and supply-chain threats while they are still weak signals—then proves every conclusion with evidence, survives hostile content, and spends high-end model capacity only where it changes the decision.

01 • Mission

Find the event before it becomes a headline.

The radar is not a news summarizer. Its advantage comes from upstream signals, source-lineage analysis, novelty measurement, and rapid but disciplined reassessment.

Cost attribution

Provider, model, agent, stage, source, run, and finding.

Untrusted content is data.

It is never allowed to redefine a task, policy, tool call, schedule, memory item, or destination.

Workflow state is deterministic.

OpenClaw cron, Task Flow, Lobster, and the database own the run—not conversational memory.

Expensive reasoning is scarce.

Code and economical models filter the stream; GPT-5.6 Sol adjudicates only the highest-value or disputed clusters.

02 • Architecture

Four planes, five trust zones, one evidence ledger.

The design mirrors the broader enterprise intelligence platform: Mesh & Runtime, Control Plane, Data Plane, and Experience Plane. Each boundary narrows authority and reduces blast radius.

Zone A — hostile internet

Pages, feeds, code, social content, documents, metadata, images, archives, and APIs.

Zone B/C — quarantine & sanitize

Raw bytes are immutable; parsers are disposable; only bounded normalized observations exit.

Zone D/E — analyze & publish

Typed evidence only. No raw content, no arbitrary URLs, no privilege inheritance.

Emergence analytics

What makes a signal early?

  • First-seen and lead-time versus media baseline
  • 15m, 1h, 6h, 24h, and 7d velocity windows
  • EWMA/CUSUM burst relative to each source's baseline
  • New entities, terms, relationships, and graph growth
  • Independent-source diversity, not raw mention count
  • EPSS jump, exploit evidence, hotfixes, package anomalies
Anti-hype logic

What prevents false urgency?

  • Repost and syndication lineage collapses echoes
  • Mainstream saturation decreases novelty
  • Skeptic searches for benign explanations
  • Contradictions reduce score and confidence
  • “Confirmed” requires a deterministic confirmation rule
  • No citations means Archive, regardless of model confidence

05 • Agent topology

Specialists disagree on purpose; policy decides what they may do.

The system uses multiple agents for independent reasoning, not as a substitute for deterministic workflow control.

Coordinator

Chief Intelligence Coordinator

GPT-5.6 Sol, maximum reasoning. Final disposition and synthesis. Sanitized evidence only; no browser, shell, secrets, schedule, or channel tools.

Collectors

Source specialists

Official advisories, code/repositories, supply chain, researcher/social, vendor/PSIRT, and infrastructure. Separate workspaces, credentials, and source budgets.

Security

Content Security Gate

Deterministic sanitizer plus risk classifier. Stops active content, hidden instructions, parser abuse, oversized artifacts, and suspicious encodings.

Economical

Extractors

Small JSON-only calls. Extract entities, versions, claims, timestamps, exploit status, and evidence roles. Low token caps and no tools.

Challenge

Skeptic

Attempts to falsify the event, identify copied sourcing, find chronology errors, expose hype, and downgrade unsupported attribution.

Gate

Citation Verifier

Checks claim entailment, evidence IDs, source independence, timestamps, qualifiers, and confidence language before publication.

08 • Experience

Discord for speed. Rich HTML for depth.

A Discord embed carries the executive signal; the attached self-contained HTML brief carries the evidence timeline, score detail, source health, and usage.

Finding card

Why now, stage, score components, confidence, momentum, first seen, affected assets, exploit status, relevance, knowns, unknowns, contradictions, actions, mappings, indicators, citations, and next check.

Truthful silence

“No material emerging threats met the publication threshold” is a valid outcome. The system never manufactures volume to make the report look active.

09 • Prompt-injection resilience

Assume the detector misses. Make the payload powerless.

Detection lowers noise; hard boundaries lower impact. No prompt can grant itself tools or move content into a more trusted zone.

Time-bomb resistance

No source-derived schedules or persistent memory; prior state is typed assessments, not transcripts; hypotheses expire without evidence.

Network resistance

Central fetch gateway blocks loopback, private, link-local, metadata, DNS rebinding, unsafe redirects, credentials in URLs, and unbounded downloads.

Report resistance

Source text is escaped. No remote scripts, forms, frames, active source HTML, or automatic source images. Restrictive CSP by default.

10 • Reliability

Designed to fail partially, recover cleanly, and never lie about coverage.

Durable state

PostgreSQL run/step records, idempotency keys, cursor checkpoints, immutable report versions, dead-letter queue, and replay.

Degraded operation

Source and model circuit breakers, fallbacks, partial reports, explicit coverage gaps, Flash budget reserve, and no silent model substitution.

Observability

11 • Evaluation

Measure whether the whole system is early, right, safe, and worth the cost.

Historical time-travel replay

Reveal artifacts only at their historical timestamps. Compare first Watch and Flash to the first credible precursor, direct evidence, and media baseline. This prevents hindsight leakage.

  • Precision@K and high-impact recall
  • Median and percentile lead time
  • False alerts and time to correction
  • Confidence calibration and source-independence accuracy
  • Cost per actionable finding

Adversarial security suite

Test every parser, source route, and agent boundary with visible, hidden, encoded, delayed, and chained injections.

  • CSS, comments, SVG, PDF annotations, OCR, code comments
  • Unicode, bidi, zero-width, base64, nested archives
  • Fake system messages, tool JSON, secret requests
  • Sybil echo and fake citations
  • Cross-document and next-run triggers
