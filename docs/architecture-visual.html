06 · Deployment

Current host, portable boundary

The current production profile is intentionally single-host. The CLI and JSON contracts keep scheduler, agent provider, and storage substitutions outside the intelligence core.

Single encrypted host Loopback services Private LAN portal Portable profile available

09 · Evals, loops, and graphs

Measure every layer, change one thing

The daily loop produces intelligence. The evaluation DAG inspects frozen acceptance, five-role reviews, source diversity, security, replay, latency, tokens, and cost before any weekly challenger can reach a human approval gate.

Daily loop live Agent + coverage evals live DAG executor implemented Weekly schedule disabled Approval + rollback
Inspect returned dataKeep every role assessment, citation, failure, provider/model ID, latency, token count, and estimated cost.
Measure surface concentrationCount origins, largest-source share, X share, non-X evidence, zero-result surfaces, and attribution gaps.
Repeat cleanlyChange one prompt, route, threshold, or source query; replay the same fixtures; promote only when anchors still pass.

10 · Activation

What runs by default and what stays gated

Plan and shadow execution are operational. Active bounded narrative is implemented but requires measured promotion; grounded policy learning remains gated until enough real analyst labels exist.
